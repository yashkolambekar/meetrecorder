Google Account / Browser Setup

Probing…

Launches the persistent Chrome on the VNC display. Use for sign-in, verification, or manual debugging. Recordings share the same browser, so leave it running.

Sign in once through VNC. The container keeps the Chrome profile in a persistent Docker volume, so recordings after the first login won't need cookies.

Step 1 — Open an SSH tunnel from your laptop

ssh -L 6080:127.0.0.1:6080 -L 3333:127.0.0.1:3333 user@server

Step 2 — Open noVNC in your laptop browser

http://localhost:6080/vnc.html

You'll see the X display :99. Click Open Chrome above to launch Chrome there.

Step 3 — Sign in to Google, complete 2FA if asked

Cookies, localStorage, IndexedDB and the Login Data database are all written to the persistent Chrome profile.

Step 4 — Verify

Click Check Profile. State should flip to READY.

VNC and noVNC bind to localhost only. They are not reachable from the internet. To reset the profile if it gets corrupted: see README.
